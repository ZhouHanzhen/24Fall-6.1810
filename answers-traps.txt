`Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?`
Registers a0-7.  a2 holds 13 in main's call to printf.

`Where is the call to function f in the assembly code for main? Where is the call to g? (Hint: the compiler may inline functions.)`
In the assembly code for main:
`26:	45b1                	li	a1,12`
0x26 is where the calls to function f and g are, they are inlined.

`At what address is the function printf located?`
In the assembly code for main:
`30:	68c000ef          	jal	6bc <printf>`
0x6bc is where the function printf located.

`What value is in the register ra just after the jalr to printf in main?`
In the assembly code for main:
```
  30:	68c000ef          	jal	6bc <printf>
  exit(0);
  34:	4501                	li	a0,0
```
0x34 is the value in the register ra just after the jalr to printf in main because that is  where printf should return back, the next instruction after the call to printf.
